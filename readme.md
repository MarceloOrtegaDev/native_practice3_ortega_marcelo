# Instalación del proyecto
    ```bash
     git clone https://github.com/MarceloOrtegaDev/native_practice3_ortega_marcelo.git
    ```
## Inicio de sessión
- Primero registra un usuario desde postman o thunder con el body indicado en el backend para que se te cree un usuario en mongoDb para que puedas utilizar e iniciar sesión
- Ya puedes Iniciar sessión en la app con el usuario y la clave que creaste

## Instala las dependencias en cada carpeta
     ```bash
        npm i
    ```
